# CloudDraw Glossary

| Term | Definition |
| :--- | :--- |
| **Availability Zone (AZ)** | An isolated data center location within an AWS Region with independent power, cooling, and networking. |
| **Stateless Server** | A backend server that stores no session or game state in local memory/disk, allowing any instance to handle any request. |
| **Redis Pub/Sub** | A publish/subscribe messaging pattern in Redis used to broadcast real-time events (strokes, chat) across multiple servers. |
| **VPC (Virtual Private Cloud)** | A logically isolated virtual network in AWS where you define IP ranges, subnets, route tables, and security controls. |
| **Security Group** | A stateful virtual firewall attached to AWS resources (ALB, ECS tasks, Redis) that controls inbound and outbound traffic. |
| **IaC (Infrastructure as Code)** | Managing and provisioning cloud infrastructure using declarative configuration files (e.g., Terraform) rather than manual clicks. |
| **Normalized Coordinates** | Representing canvas positions as fractions in `[0, 1]` rather than pixels so drawings scale identically across screen sizes. |
| **Stroke Batching** | Grouping multiple pointer points into a single message every ~40 ms to reduce WebSocket and Pub/Sub overhead. |
| **Pointer Events** | A unified browser event model (`pointerdown`, `pointermove`, `pointerup`) supporting mouse, touch, and pen input. |
| **WebSocket** | A full-duplex, persistent communication protocol over a single TCP connection, ideal for real-time games. |
| **Server-Authoritative** | An architecture where the server owns the source of truth for game rules, timers, and scoring to prevent client cheating. |
| **Rate Limiting** | Restricting how many requests or messages a client can send in a time window to protect against abuse and floods. |
| **Distributed Lock** | A shared lock stored in Redis with a TTL so only one server instance owns a room's timer at a time. |
| **Lua Script (Redis)** | A script executed atomically inside Redis to perform read-check-write operations without race conditions. |
| **Sticky Sessions** | Routing a client's requests always to the same backend server; avoided here by keeping servers stateless. |
| **Exponential Backoff with Jitter** | Increasing retry delays (`1s, 2s, 4s...`) plus randomness so reconnecting clients don't thundering-herd the server. |
| **Presigned URL** | A time-limited URL generated by the server using IAM credentials that grants a client temporary permission to upload/download directly to S3. |
| **DynamoDB On-Demand** | A serverless NoSQL billing mode where you pay per read/write request with zero idle cost. |
| **Partition Key** | The primary attribute DynamoDB hashes to distribute items across storage partitions. |
| **NAT Gateway** | A managed AWS service allowing instances in private subnets to make outbound internet requests without receiving inbound internet traffic. |
| **Gateway Endpoint** | A free VPC endpoint that routes S3 or DynamoDB traffic privately over the AWS network, bypassing the NAT Gateway. |
| **Security Group vs NACL** | Security Groups are stateful resource-level firewalls; NACLs are stateless subnet-level firewalls. |
| **Least Privilege** | Granting a user, role, or network resource only the minimum permissions/ports required to do its job. |
